Type Hints in Python: A Detailed Guide
Type hints are a feature in Python that allow you to explicitly declare the expected data types of variables, function parameters, and return values. They were introduced in Python 3.5 (PEP 484) and have since become a standard for writing more maintainable and self-documenting code.

Why Use Type Hints?

Improved Code Readability: Makes it clear what types of data a function expects and returns.
Better IDE Support: Enables autocompletion, type checking, and error detection in editors like VS Code or PyCharm.
Early Bug Detection: Helps catch type-related errors before runtime.
Self-Documenting Code: Acts as documentation for other developers (or your future self).

Type Hints in Practice
Example 1: Function with Type Hints
python
Copy

from typing import List, Dict, Optional

def calculate_average(numbers: List[float]) -> float:
    if not numbers:
        raise ValueError("Empty list")
    return sum(numbers) / len(numbers)

def process_data(data: Dict[str, List[int]]) -> Dict[str, float]:
    result = {}
    for key, values in data.items():
        result[key] = sum(values) / len(values)
    return result



Example 2: Class with Type Hints

Copy

from typing import List, Optional

class Book:
    def __init__(self, title: str, author: str, year: int):
        self.title = title
        self.author = author
        self.year = year

class Library:
    def __init__(self):
        self.books: List[Book] = []

    def add_book(self, book: Book) -> None:
        self.books.append(book)

    def find_book(self, title: str) -> Optional[Book]:
        for book in self.books:
            if book.title == title:
                return book
        return None

Theory for Interview Preparation
1. What Are Type Hints?
Type hints are annotations in Python code that indicate the expected data types of variables, function parameters, and return values. They are defined using the syntax variable: type and def func(param: type) -> return_type:.
2. Dynamic vs. Static Typing

Dynamic Typing: Python is dynamically typed, meaning types are checked at runtime. Variables can hold values of any type, and types are associated with values, not variables.
Static Typing: Types are checked at compile time. Type hints bring some benefits of static typing to Python, but Python remains dynamically typed.
3. Benefits of Type Hints

Readability: Makes code easier to understand.
Tooling Support: Enables better autocompletion and error detection in IDEs.
Maintainability: Helps catch type-related bugs early.
Documentation: Serves as inline documentation.
4. Optional and Union Types

Optional[int] is equivalent to Union[int, None]. It indicates that a value can be either an integer or None.
Union[int, str] indicates that a value can be either an integer or a string.
5. TypeVar and Generics

TypeVar is used to define generic types. For example, T = TypeVar('T') can be used to write functions that work with any type.
Example:
python
Copy

from typing import TypeVar, List

T = TypeVar('T')

def first_item(items: List[T]) -> T:
    return items[0]




6. TypedDict

TypedDict is used to define dictionaries with a fixed set of keys and their types.
Example:
python
Copy

from typing import TypedDict

class Person(TypedDict):
    name: str
    age: int




7. Callable Type Hints

Callable[[Arg1Type, Arg2Type], ReturnType] is used to annotate functions that take other functions as arguments.
Example:
python
Copy

from typing import Callable

def apply(func: Callable[[int, int], int], a: int, b: int) -> int:
    return func(a, b)




8. Forward References

When a type hint refers to a class that hasn’t been defined yet, you can use a string literal.
Example:
python
Copy

class TreeNode:
    def __init__(self, value: int, left: 'TreeNode' = None, right: 'TreeNode' = None):
        self.value = value
        self.left = left
        self.right = right




9. Runtime Behavior of Type Hints

Type hints are ignored at runtime by the Python interpreter. They are purely for static analysis and tooling.
Example:
python
Copy

def add(a: int, b: int) -> int:
    return a + b

print(add("hello", "world"))  # No error at runtime, but type checkers will flag this




10. Type Checkers

Tools like mypy, pyright, and pytype can statically analyze Python code with type hints to catch type-related errors before runtime.
